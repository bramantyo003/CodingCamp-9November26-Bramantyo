# Expense & Budget Visualizer

A mobile-friendly web app to track daily spending. It shows your total balance, a history of transactions, and a pie chart of spending by category.

Built with HTML, CSS, and vanilla JavaScript. No backend: all data is saved in the browser's Local Storage.

## Features

**Required (MVP)**
- Input form with Item Name, Amount, and Category (Food, Transport, Fun), with validation
- Scrollable transaction list with the ability to delete items
- Total balance at the top that updates automatically
- Pie chart (Chart.js) of spending by category that updates automatically

**Optional challenges (3 chosen)**
- Sort transactions by newest, amount, or category
- Highlight spending over a set limit (items and total)
- Dark / light mode toggle

## Run locally

Open `index.html` in a modern browser (Chrome, Firefox, Edge, Safari). An internet connection is needed to load Chart.js from the CDN.
